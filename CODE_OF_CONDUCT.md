# Contributor Code of Conduct

## Our commitment

We aim to make participation in Poster Agent respectful, constructive, and focused on improving the project. Contributors should be treated with dignity regardless of background, identity, experience level, or viewpoint.

## Expected behavior

- Be respectful, specific, and constructive in issues, reviews, and discussions.
- Critique ideas and code, not people.
- Accept good-faith corrections and differing technical opinions.
- Respect privacy, licensing, and data permissions.
- Do not publish secrets, customer data, private logs, or unauthorized assets.
- Do not claim synthetic tests or mock outputs establish real-world quality.

## Unacceptable behavior

Harassment, discrimination, personal attacks, threats, doxxing, deliberate disruption, and publishing private information without permission are not acceptable.

## Scope and reporting

This policy applies to project spaces, including GitHub issues, pull requests, reviews, and project-related public discussions.

Report conduct concerns privately to the repository owner through a non-public GitHub contact method. Do not post sensitive details in a public issue. The project currently does not promise a response-time SLA; reports will be reviewed as capacity permits.

## Enforcement

The maintainers may edit or remove violating content, close discussions, or restrict participation based on the severity and context of the behavior. They will explain actions where reasonably possible while protecting privacy.

This code of conduct does not grant any license to project code, data, or assets. See the repository's open-source release checklist for the current licensing status.
