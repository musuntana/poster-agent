# M1 技能验证（亲手做，不靠背术语）

| 验收 | 你需要能够解释和亲自修改 |
| --- | --- |
| `scripts/generate_demo.py` 运行成功 | Pillow 图片、透明通道及背景合成 |
| 浏览器能上传图片生成海报 | `UploadFile`/表单、Pydantic 校验 |
| `background_mode=local` 能工作 | 本地背景与 AI API 的区别 |
| `background_mode=ai` 返回真实生图 | 环境变量、Bearer Token、HTTP 请求、返回数据 |
| 价格从 199 改成 189 | 不重新调用 AI；读取历史素材并渲染新版本 |
| 无法识别的文件被拒绝 | 输入校验、异常和错误码 |
| `pytest` 通过 | 单元测试/集成测试的区别 |
| 版本 v1/v2 不覆盖 | 数据版本与不可变输出 |

## 动手修改练习

1. 将默认按钮文案 `立即抢购` 改成 `马上购买`，修改哪个文件？
2. 将版式尺寸由 1024 改为更大尺寸，哪些坐标也要修改？这说明什么设计问题？
3. 把价格改成极长的数值，当前排版如何自动缩小？
4. 关闭 API Key，在 AI 模式生成时返回什么 HTTP 状态？为什么不能默默回退到本地？
5. 模拟 `read_upload` 收到 PDF 文件，如何通过自动测试证明拒绝了它？

每完成一个问题，在 Git 提交中说明“需求 → 修改 → 测试 → 结果”。
