# M5n：本地配色选择器

在“01 · 新建海报”中，运营人员可以点击 5 张配色卡快速填写现有的 `style` 字段；原本的自由输入仍然可用。所有卡片都是**本地渐变背景**，不是完整海报版式模板。

| 配色 | 传入字段 `style` | 场景示例 |
| --- | --- | --- |
| 科技蓝 | `蓝色科技风` | 3C/数码 |
| 浪漫粉 | `粉色浪漫` | 礼盒/美妆 |
| 自然绿 | `绿色自然` | 健康/生活 |
| 活力橙 | `橙色暖阳` | 促销/节庆 |
| 梦幻紫 | `紫色梦幻` | 创意/时尚 |

## 规则和兼容性

- 点击卡片会更新已有的 `<input name="style">`，没有增加 API 字段或对原有 `PosterSpec` 加约束；旧调用方兼容。
- 手动输入匹配预设名称时会高亮卡片；自定义字符串按照原有本地关键字匹配规则回落，不把任意字符串误报为已验证模板。
- 恢复 Brief 草稿时，会按恢复后的 `style` 同步卡片；已批准 Brief 不能通过选卡绕开已确认规格。确实需要更换风格时，先退出该审核任务或创建新的审核流程。
- 背景模式是独立字段。选卡只负责风格说明，不会擅自将 `ai` 切换到 `local`。选中 Qwen 模式仍需要 API Key，且可能收费；要免费请明确选择“本地渐变”。
- 渲染仍沿用 `local_background`、`compose` 和原有素材存储，**不会自动验证广告合规性、商品保真、OCR 或人工视觉质量**。
- 键盘可通过 Tab 选中卡片并回车操作，`aria-pressed` 反映当前精确匹配的选择。

## 验证

```bash
uv run --locked ruff check app tests
uv run --locked python -m pytest -q tests/test_compositor.py tests/test_style_picker.py
```

基于规则的本地渐变可以改善选择体验，但**不代表已经实现 Canva 风格的多布局模板系统**。真正的版式模板应在后续单独设计布局参数、预览和版本化存储。
