# M5m：完整文案编辑与版本冲突保护

此功能面向单机本地 Poster Agent，不增加付费图像模型调用。

## 浏览器操作

1. 在主页面生成海报或从本地审核队列打开最新版本。
2. 在“03 · 修改内容”修改主标题、副标题、活动价、原价和 CTA；副标题、原价可清空。
3. 点击“保存新版本”：沿用保存的原商品、Logo 和背景，重新排版生成独立 PNG 版本。
4. 若另一个浏览器窗口已保存更高版本，旧窗口会收到 HTTP **409**；点击“加载最新版本”查看新内容，再决定是否重新编辑。不会在冲突时创建新版本。

编辑 **不能**改变已经生成的背景模式、商品原图或 Logo。需要改变素材时应新建海报。调整文字/价格后，需要针对新版本重新执行验收；旧 OCR 与人工标签不能视为新版本通过。

## API 兼容性

`POST /api/posters/{poster_id}/revisions` 原有字段保持不变，增加**可选** `expected_version`，必须是大于等于 1 的整数。

```json
{
  "expected_version": 2,
  "title": "活动限时",
  "subtitle": "",
  "price": "179",
  "original_price": null,
  "cta": "立即购买"
}
```

- 当 `expected_version` 与服务端最新版本不同时，返回 **409**，不写入新版本。
- 只传 `expected_version` 不算业务字段修改，返回 **422**。
- 未传 `expected_version` 的旧 API 客户端仍可调用原有功能；**旧客户端不具备冲突保护**。
- 比较最新版本、重新排版和写版本都使用同一个进程内 `RLock`；不支持多进程/多副本的并发事务承诺。

## 最小回归验证

```bash
uv run --locked ruff check app tests
uv run --locked python -m pytest -q tests/test_api.py
```

相关测试包括：修改副标题和 CTA、清空原价、旧版 PNG 和商品素材保持不变、陈旧版本拒绝覆盖、老客户端兼容、表单暴露五项可编辑内容。

**非验收声明：** 浏览器可编辑功能和版本冲突保护不等于真实商品质量、PaddleOCR 或生产部署验证已通过。
